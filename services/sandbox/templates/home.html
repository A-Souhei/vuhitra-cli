Context Management System

Manage your LLM contexts across different scopes and modes

Eternals

Persistent cross-session contexts for normal mode. Survive CLI restarts.

/eternal load @file.md
Manage Eternals
Pillars

Coding mode persistent contexts. Auto-load from pillars/ directory.

/pillar load @file.md
Manage Pillars
Ephemerals

Session-scoped contexts for normal mode. Cleared when session ends.

/ephemeral load @file.txt
Manage Ephemerals
Vanishers

Coding mode session contexts. Requires mirrored files.

/vanisher load @file.txt
Manage Vanishers
Mirrors

File synchronization between host and sandbox. Required for vanishers.

/mirror do @data
Manage Mirrors
